Support and getting started

PO Audit & Stocky Rescue is operated by Nguyễn Văn Hùng. Contact support@vievot.com for app support. For privacy or data requests, use support@vievot.com and review the privacy policy.

Prepare your files

Use a purchase order and supplier invoice. CSV, TSV and XLSX are supported; each file may contain up to 5,000 rows and 2 MB. Keep headers and stable SKU or supplier-SKU identifiers. PDF/OCR is not included. Review tax, shipping and discounts separately.

Import and map

  1. Open the app from Shopify Admin.
  2. Choose Purchase order / Stocky archive and select your file.
  3. Select Preview & map columns. Check currency, product identifiers, quantities and unit-cost mappings.
  4. Select Save mapped document, then repeat for Supplier invoice.

An identical saved file/type/mapping reuses its source document. Changing the selected file or type requires a fresh preview. Formulas without supported cached values, macros, external links and encrypted XLSX files are rejected.

Compare and review

Select the purchase order and invoice and run the comparison. Optional receiving snapshots replace received quantities as a complete receiving snapshot; select partial shipments exactly once. Review every HOLD reason and source-row reference. Unknown values and currency conflicts remain on HOLD.

A payment-review label never authorizes or makes a payment. Use the saved report link to return to the same report and its CSV export. Your first full report remains available without an active plan. Further comparisons and archive/history access require verified current entitlement; Shopify shows available pricing before you approve a plan. Access follows your verified current subscription.

Reconnect, import or plan problems

  • If the app asks you to reconnect, reopen it through Shopify Admin.
  • If an import fails, check headers, rows, file size and supported spreadsheet values. Correct the source file and map it again.
  • If a report is missing, use its saved ID/link in the same shop. Reports belonging to another shop are not made available by entering an ID.
  • If plan verification is unavailable, do not purchase again to resolve the outage. A pending cancellation can remain active until the actual subscription ends.

Delete data without a paid plan

In the app, expand Manage data deletion (always available) and choose Delete document & linked reports. To remove all shop app data, expand Delete all app data, type ERASE and confirm. Single-document deletion keeps first-free usage; shop erasure removes it. Uninstall and shop-redact processing are described in the privacy policy. Plan cancellation itself does not erase your saved records.

What to include in a support request

Email support@vievot.com with the shop domain, approximate time, the action taken, exact visible error and report ID if relevant. A cropped screenshot or synthetic/redacted sample is usually sufficient to start. Do not send Shopify passwords, access tokens, session keys, billing secrets or complete real invoices in the initial message.
